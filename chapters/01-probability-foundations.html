Chapter 1: Foundations of Probability Theory

Building rigorous mathematical foundations for statistical reasoning

1.1 Introduction

Probability theory forms the mathematical foundation of statistics, machine learning, and data science. Understanding probability rigorously is essential for developing and analyzing ML algorithms, quantifying uncertainty, and making principled decisions from data.

Why Probability Matters in ML/DL

Modern machine learning is fundamentally probabilistic:

  • Neural networks use probabilistic loss functions (cross-entropy)
  • Bayesian deep learning quantifies model uncertainty
  • Generative models (VAEs, GANs) explicitly model probability distributions
  • Reinforcement learning uses probabilistic policies

1.2 Sample Spaces and Events

1.2.1 Sample Space

Definition: Sample Space

The sample space $\Omega$ is the set of all possible outcomes of a random experiment. Each element $\omega \in \Omega$ is called a sample point or outcome.

Example 1.1: Sample Spaces

  1. Coin flip: $\Omega = \{H, T\}$
  2. Die roll: $\Omega = \{1, 2, 3, 4, 5, 6\}$
  3. Image classification: $\Omega = \{\text{cat}, \text{dog}, \text{bird}, \ldots\}$
  4. Continuous measurement: $\Omega = \mathbb{R}$ or $\Omega = [0, \infty)$
  5. Neural network output: $\Omega = [0, 1]^K$ (K-class probabilities)

1.2.2 Events

Definition: Event

An event $A$ is a subset of the sample space: $A \subseteq \Omega$. The collection of all events forms a σ-algebra (sigma-algebra) $\mathcal{F}$.

Definition: σ-Algebra

A collection $\mathcal{F}$ of subsets of $\Omega$ is a σ-algebra if:

  1. $\Omega \in \mathcal{F}$ (the sample space is an event)
  2. If $A \in \mathcal{F}$, then $A^c \in \mathcal{F}$ (closed under complementation)
  3. If $A_1, A_2, \ldots \in \mathcal{F}$, then $\bigcup_{i=1}^{\infty} A_i \in \mathcal{F}$ (closed under countable unions)

1.2.3 Set Operations on Events

Events can be combined using standard set operations:

  • Union: $A \cup B$ (either A or B occurs)
  • Intersection: $A \cap B$ (both A and B occur)
  • Complement: $A^c$ (A does not occur)
  • Difference: $A \setminus B = A \cap B^c$ (A occurs but not B)

1.3 Axioms of Probability

The modern axiomatic foundation of probability was established by Kolmogorov (1933). These axioms provide a rigorous mathematical framework for reasoning about uncertainty.

Kolmogorov's Axioms

A probability measure $P$ on a sample space $\Omega$ with σ-algebra $\mathcal{F}$ is a function $P: \mathcal{F} \to [0, 1]$ satisfying:

  1. Non-negativity: $P(A) \geq 0$ for all $A \in \mathcal{F}$
  2. Normalization: $P(\Omega) = 1$
  3. Countable additivity: For any countable collection of disjoint events $A_1, A_2, \ldots$:
    $$P\left(\bigcup_{i=1}^{\infty} A_i\right) = \sum_{i=1}^{\infty} P(A_i)$$

1.3.1 Consequences of the Axioms

Many useful properties follow directly from Kolmogorov's axioms:

Theorem 1.1: Basic Properties

  1. $P(\emptyset) = 0$ (probability of impossible event)
  2. $P(A^c) = 1 - P(A)$ (complement rule)
  3. If $A \subseteq B$, then $P(A) \leq P(B)$ (monotonicity)
  4. $P(A \cup B) = P(A) + P(B) - P(A \cap B)$ (addition rule)

Proof of Complement Rule

We have $\Omega = A \cup A^c$ and $A \cap A^c = \emptyset$. By axioms 2 and 3:

$$1 = P(\Omega) = P(A \cup A^c) = P(A) + P(A^c)$$

Therefore, $P(A^c) = 1 - P(A)$. □

1.3.2 Union Bound (Boole's Inequality)

Theorem 1.2: Union Bound

For any events $A_1, A_2, \ldots, A_n$ (not necessarily disjoint):

$$P\left(\bigcup_{i=1}^{n} A_i\right) \leq \sum_{i=1}^{n} P(A_i)$$

This is fundamental in ML for bounding error probabilities in multiple hypothesis testing.

1.4 Conditional Probability

Conditional probability allows us to update our beliefs based on new evidence—the foundation of Bayesian inference and many ML algorithms.

Definition: Conditional Probability

Given events $A$ and $B$ with $P(B) > 0$, the conditional probability of $A$ given $B$ is:

$$P(A \mid B) = \frac{P(A \cap B)}{P(B)}$$

1.4.1 Chain Rule

Theorem 1.3: Chain Rule (Product Rule)

For events $A_1, A_2, \ldots, A_n$:

$$P(A_1 \cap A_2 \cap \cdots \cap A_n) = P(A_1) \cdot P(A_2 \mid A_1) \cdot P(A_3 \mid A_1 \cap A_2) \cdots P(A_n \mid A_1 \cap \cdots \cap A_{n-1})$$

This is used extensively in probabilistic graphical models and autoregressive models.

1.5 Independence

Definition: Independence

Events $A$ and $B$ are independent if:

$$P(A \cap B) = P(A) \cdot P(B)$$

Equivalently (if $P(B) > 0$): $P(A \mid B) = P(A)$

Common Misconception

Independence ≠ Disjointness!

If $A$ and $B$ are disjoint with positive probability, they are dependent:

$$P(A \mid B) = \frac{P(A \cap B)}{P(B)} = \frac{0}{P(B)} = 0 \neq P(A)$$

Definition: Mutual Independence

Events $A_1, \ldots, A_n$ are mutually independent if for every subset $I \subseteq \{1, \ldots, n\}$:

$$P\left(\bigcap_{i \in I} A_i\right) = \prod_{i \in I} P(A_i)$$

1.6 Bayes' Theorem

Bayes' theorem is the cornerstone of Bayesian statistics and machine learning. It provides a principled way to update beliefs based on evidence.

Theorem 1.4: Bayes' Theorem

For events $A$ and $B$ with $P(A), P(B) > 0$:

$$P(A \mid B) = \frac{P(B \mid A) \cdot P(A)}{P(B)}$$

Where:

  • $P(A \mid B)$ is the posterior probability
  • $P(B \mid A)$ is the likelihood
  • $P(A)$ is the prior probability
  • $P(B)$ is the marginal likelihood or evidence

Example 1.2: Medical Diagnosis with Bayes' Theorem

A disease affects 1% of the population. A test for the disease has:

  • Sensitivity (true positive rate): 95%
  • Specificity (true negative rate): 90%

What is the probability a person has the disease given a positive test?

Solution:

Let $D$ = "has disease", $T^+$ = "tests positive"

Given: $P(D) = 0.01$, $P(T^+ \mid D) = 0.95$, $P(T^- \mid D^c) = 0.90$

We need: $P(D \mid T^+)$

First, find $P(T^+)$ using the law of total probability:

$$P(T^+) = P(T^+ \mid D)P(D) + P(T^+ \mid D^c)P(D^c)$$ $$= 0.95 \times 0.01 + 0.10 \times 0.99 = 0.1085$$

Now apply Bayes' theorem:

$$P(D \mid T^+) = \frac{P(T^+ \mid D) \cdot P(D)}{P(T^+)} = \frac{0.95 \times 0.01}{0.1085} \approx 0.0876$$

So only about 8.76% of people who test positive actually have the disease!

1.7 Law of Total Probability

Theorem 1.5: Law of Total Probability

If $B_1, B_2, \ldots, B_n$ is a partition of $\Omega$ (i.e., mutually exclusive and exhaustive), then for any event $A$:

$$P(A) = \sum_{i=1}^{n} P(A \mid B_i) P(B_i)$$

This is essential for marginalization in probabilistic models.

1.8 Python Implementation

Let's implement key concepts using Python:

Python: Probability Foundations
import numpy as np
import matplotlib.pyplot as plt
from scipy import stats
import seaborn as sns

class ProbabilitySpace:
    """
    A class to represent a finite probability space.
    """
    def __init__(self, outcomes, probabilities=None):
        """
        Parameters:
        -----------
        outcomes : list
            List of possible outcomes
        probabilities : list or None
            Probability of each outcome (uniform if None)
        """
        self.outcomes = outcomes
        if probabilities is None:
            # Uniform distribution
            self.probabilities = np.ones(len(outcomes)) / len(outcomes)
        else:
            assert len(probabilities) == len(outcomes), "Length mismatch"
            assert np.allclose(sum(probabilities), 1.0), "Must sum to 1"
            assert all(p >= 0 for p in probabilities), "Must be non-negative"
            self.probabilities = np.array(probabilities)

        # Create probability dictionary
        self.prob_dict = dict(zip(outcomes, self.probabilities))

    def P(self, event):
        """
        Calculate probability of an event.

        Parameters:
        -----------
        event : set or list
            Event (subset of outcomes)

        Returns:
        --------
        float : Probability of the event
        """
        if callable(event):
            # Event defined by a function
            event = [o for o in self.outcomes if event(o)]

        prob = sum(self.prob_dict.get(outcome, 0) for outcome in event)
        return prob

    def conditional_prob(self, A, B):
        """
        Calculate P(A|B) = P(A ∩ B) / P(B)
        """
        A_set = set(A) if not callable(A) else set([o for o in self.outcomes if A(o)])
        B_set = set(B) if not callable(B) else set([o for o in self.outcomes if B(o)])

        P_B = self.P(B_set)
        if P_B == 0:
            raise ValueError("P(B) = 0, conditional probability undefined")

        A_and_B = A_set.intersection(B_set)
        return self.P(A_and_B) / P_B


# Example 1: Fair die
die = ProbabilitySpace(outcomes=[1, 2, 3, 4, 5, 6])

# P(roll is even)
even = {2, 4, 6}
print(f"P(even) = {die.P(even)}")  # 0.5

# P(roll > 4)
greater_than_4 = lambda x: x > 4
print(f"P(> 4) = {die.P(greater_than_4)}")  # 0.333...

# Conditional probability: P(even | > 3)
print(f"P(even | > 3) = {die.conditional_prob({2, 4, 6}, {4, 5, 6})}")  # 0.333...


# Example 2: Medical diagnosis (Bayes' theorem)
def bayes_theorem(prior, likelihood, evidence):
    """
    Calculate posterior using Bayes' theorem.

    P(H|E) = P(E|H) * P(H) / P(E)
    """
    posterior = (likelihood * prior) / evidence
    return posterior

# Disease example
P_D = 0.01  # Prior: 1% have disease
P_pos_given_D = 0.95  # Sensitivity
P_pos_given_not_D = 0.10  # False positive rate

# Law of total probability for P(positive test)
P_pos = P_pos_given_D * P_D + P_pos_given_not_D * (1 - P_D)

# Posterior: P(disease | positive test)
P_D_given_pos = bayes_theorem(P_D, P_pos_given_D, P_pos)
print(f"\nP(disease | positive test) = {P_D_given_pos:.4f}")


# Example 3: Visualizing Bayes' theorem
def visualize_bayes_update(prior_alpha=1, prior_beta=1,
                           successes=7, failures=3):
    """
    Visualize Bayesian updating with Beta-Binomial conjugacy.
    """
    x = np.linspace(0, 1, 1000)

    # Prior
    prior = stats.beta(prior_alpha, prior_beta)

    # Posterior (Beta is conjugate prior for Binomial)
    posterior = stats.beta(prior_alpha + successes,
                           prior_beta + failures)

    plt.figure(figsize=(10, 6))
    plt.plot(x, prior.pdf(x), label='Prior', linewidth=2)
    plt.plot(x, posterior.pdf(x), label='Posterior', linewidth=2)
    plt.axvline(successes/(successes+failures),
                color='red', linestyle='--',
                label=f'MLE = {successes/(successes+failures):.2f}')
    plt.xlabel('θ (probability of success)')
    plt.ylabel('Density')
    plt.title('Bayesian Update: Prior → Posterior')
    plt.legend()
    plt.grid(True, alpha=0.3)
    plt.show()

# Example 4: Monte Carlo simulation for probability estimation
def monte_carlo_probability(event_function, num_samples=100000):
    """
    Estimate probability using Monte Carlo simulation.

    Parameters:
    -----------
    event_function : callable
        Function that returns True if event occurs
    num_samples : int
        Number of Monte Carlo samples
    """
    successes = sum(1 for _ in range(num_samples) if event_function())
    return successes / num_samples

# Example: Probability that sum of 2 dice >= 10
def two_dice_sum_geq_10():
    die1 = np.random.randint(1, 7)
    die2 = np.random.randint(1, 7)
    return (die1 + die2) >= 10

prob_estimate = monte_carlo_probability(two_dice_sum_geq_10)
theoretical = 6/36  # {(4,6), (5,5), (5,6), (6,4), (6,5), (6,6)}
print(f"\nMonte Carlo estimate: {prob_estimate:.4f}")
print(f"Theoretical probability: {theoretical:.4f}")

1.9 Exercises

Exercise 1.1

Easy

Prove that for any events $A$ and $B$: $$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$

Proof:

Note that $A \cup B = A \cup (B \setminus A)$ where $A$ and $B \setminus A$ are disjoint.

By countable additivity:

$$P(A \cup B) = P(A) + P(B \setminus A)$$

Also, $B = (A \cap B) \cup (B \setminus A)$ where the sets are disjoint, so:

$$P(B) = P(A \cap B) + P(B \setminus A)$$ $$P(B \setminus A) = P(B) - P(A \cap B)$$

Substituting back:

$$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$

□

Exercise 1.2

Medium

Show that if events $A$ and $B$ are independent, then $A$ and $B^c$ are also independent.

Proof:

We need to show that $P(A \cap B^c) = P(A) \cdot P(B^c)$.

Note that $A = (A \cap B) \cup (A \cap B^c)$ where the sets are disjoint.

$$P(A) = P(A \cap B) + P(A \cap B^c)$$

Since $A$ and $B$ are independent: $P(A \cap B) = P(A) \cdot P(B)$

$$P(A \cap B^c) = P(A) - P(A \cap B) = P(A) - P(A)P(B)$$ $$= P(A)(1 - P(B)) = P(A) \cdot P(B^c)$$

Therefore, $A$ and $B^c$ are independent. □

Exercise 1.3

Hard

(Monty Hall Problem) A game show has 3 doors. Behind one is a car, behind the others are goats. You pick door 1. The host (who knows what's behind each door) opens door 3, revealing a goat. Should you switch to door 2?

Solution using Bayes' Theorem:

Let $C_i$ = "car is behind door $i$", $H_3$ = "host opens door 3"

Initially: $P(C_1) = P(C_2) = P(C_3) = 1/3$

We need: $P(C_2 \mid H_3)$ vs $P(C_1 \mid H_3)$

Likelihoods:

  • $P(H_3 \mid C_1) = 1/2$ (host can open 2 or 3)
  • $P(H_3 \mid C_2) = 1$ (host must open 3)
  • $P(H_3 \mid C_3) = 0$ (host won't reveal car)

By law of total probability:

$$P(H_3) = \frac{1}{2} \cdot \frac{1}{3} + 1 \cdot \frac{1}{3} + 0 \cdot \frac{1}{3} = \frac{1}{2}$$

By Bayes' theorem:

$$P(C_1 \mid H_3) = \frac{P(H_3 \mid C_1) P(C_1)}{P(H_3)} = \frac{(1/2)(1/3)}{1/2} = \frac{1}{3}$$ $$P(C_2 \mid H_3) = \frac{P(H_3 \mid C_2) P(C_2)}{P(H_3)} = \frac{(1)(1/3)}{1/2} = \frac{2}{3}$$

Conclusion: You should switch! Switching doubles your probability of winning. □
